# Run and deploy UoG Family

This contains everything you need to run the UoG Family social platform locally.

UoG Family is a comprehensive digital hub for connecting the University of Gondar community—students, faculty, alumni, and staff.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
